# 斗风筝

双线割线对战小游戏：Canvas + TypeScript，物理模拟放飞（升力 / 阻力 / 线张力平衡），
阵风忽大忽小，收线爬升、放线下沉，两根 300 节点的线交叉互磨，先断者输。

## 玩

直接双击打开 `index.html`（`game.js` 已打包好，无需服务器）。

- **选择页**：选风筝（北京沙燕 / 潍坊硬翅 / 南通板鹞 / 天津软翅 / 阳江打斗筝）和线（棉线 / 一粉 / 二粉 / 三粉玻璃线，越锋利越脆）
- **试飞页**：自由放飞，实时显示放飞角 vs 升阻比理论值
- **对战页**：与 AI 斗线，磨断对方的线即胜
- **战绩页**：本地战绩（localStorage）

## 操作

| 按键 | 动作 |
|---|---|
| A / D 或 ← / → | 走动换位 |
| W / S 或 ↑ / ↓ | 收线 / 放线 |
| 鼠标滚轮 | 收放线（脉冲式，适合猛放） |

割线手法：先让自己的线挂上对方的线，然后**猛放线**——线从对方线上高速滑过，
按相对滑动速度 × 玻璃粉等级互相磨损。挂了线不动是割不断的。

## 开发

```
npm install
npm run build      # esbuild 打包 src/main.ts → game.js（单文件，IIFE）
npm run typecheck  # tsc --noEmit
npm run verify     # 无头物理验证（node）
```

## 物理与验证（`npm run verify`）

- **放飞角**：5 种风筝 × 2 种稳定风速（6/8 m/s），实测稳态放飞角与理论值
  `atan(升力系数/阻力系数)` 的偏差全部 ≤ 3°（实测最大 2.75°）
- **性能**：两条各 300 节点的线，交叉判定（均匀网格 + 线段最近点）+ 磨损，
  120Hz 下单步约 0.23ms（预算 8.33ms）
- **手感方向**：收线时径向收线增大相对风、升力过剩、放飞角冲高；放线时张力松、角度走低
- **磨损**：相对滑动速度低于 0.25 m/s 不磨损；AI 对 AI 冒烟局可正常分出胜负

### 物理模型要点

- 风筝：质点。升力 ⊥ 相对风、阻力 ∥ 相对风、重力、姿态阻尼；线的张力通过
  **系留约束**（锚点到风筝距离 ≤ 当前线长）传入——绷紧时约束投影就是张力
- 线：300 个有质量的节点，Verlet 积分 + 距离约束（两端固定），有重力会下垂、
  有气动阻力会被风吹弯；阵风停了线就松垮下来
- 风：基础风 + 多层正弦阵风 + 突发阵风事件 + 低空边界层（低空风弱）
- 断线：风筝进入翻滚自由体（只剩阻力），顺风飘走落地
